# R360: guarded character diffuse reconstruction

R359 run153612-79096-1 completed twelve images with zero failures, all material groups replaced, nine admitted PSOs, active RR throughout and clamp60. Dense neck/jaw grain is visible in the original base diffuse times material and dimmed diffuse images. Specular alone does not reproduce the dense pattern. This identifies diffuse as the priority, not proof that every noise source is diffuse or that its producer alone is responsible.

R360 reconstructs the existing native diffuse buffer immediately after its load and BEFORE material multiplication. It retains the center sample with weight4 and gathers eight neighboring2x2 tiles with axial weights2/diagonal weights1. Each neighbor follows the original packed GBufferReconstruction map for the current pixel parity. Out-of-bounds candidates and invalid remapped coordinates are rejected. Material ID and the separate GBuffer normal mask bit must match; the decoded stereographic view normals must have dot product above0.95, with a smooth squared weight. Strong relative RGB radiance changes fade to zero weight. Only diffuse RGB changes; material/detail textures, specular, rig lighting, fog, alpha/depth/coverage operations and all original resource reads remain exact. No new bindings, full-screen passes, render targets or temporal history.

The reconstruction only runs for native sample count<=1. MSAA>1 retains the original diffuse read because neighboring coverage-index selection is not validated. Nonfinite or magnitude>=1e20 center values use the native read; such neighbors are excluded. No sample clamp is applied to accepted lighting. The center guarantees positive normalization. At most34 additional texture loads and one dimension query per character pixel; game GPU cost has not been measured. The existing HQ rig and near history stay enabled.

Material/normal/mask guards are NOT a depth or object-identity guard. Nearby overlapping surfaces with matching guides can still contribute; radiance gating reduces but does not prove elimination of that risk. In-game silhouette, hair, shadow-edge stability and performance need comparison. The shader is only installed for the twelve exact audited native families.

RIG STABLE selects reconstructed HQ plus near history by default. TEST JESSE compares original stable / reconstructed full / original diffuse / reconstructed diffuse / reconstructed diffuse at quarter radiance / reconstructed full repeat, two full-client JPEGs each. The original-stable phase retains near history for a controlled comparison. RR mode is read-only throughout and clamp60 remains.

Validation:384 emitted-token cases across12 families compare with an independently expressed image-space oracle: remap parity, odd borders, material/normal/mask/radiance edges, constant radiance, nonfinite values and MSAA fallback. Every original temporary except diffuse RGB is preserved, and removing the injected block recovers the entire original HQ shader. Existing2400 component arithmetic cases and960 HQ rig cases remain. Windows additionally dispatches the exact emitted filter block on WARP in eight texture fixtures and checks readbacks against the oracle, then creates every full character PSO and stripped-metadata equivalent. None of this is an in-game quality/performance claim.
