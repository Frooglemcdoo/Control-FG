# R461: performance baseline and four-ray candidate

User accepts R460 as improved but still sees orange neck noise; reports 10-15 FPS
loss and requests both ten- and four-ray packages. R460 capture 20261117-222901:
ten valid/guided snapshots, zero inside-uncovered flags; fitted radii active
(.25-.433m). No pass timings exist in this ZIP. No measured FPS recovery claim.

Normal runtime previously allocated training, cells, output target, and upload
ray record each invocation. Cache up to eight private training/cell/record sets
only after existing CollectReady reports both stages submitted, GPU complete,
and both command-list recording generations sealed. Reuse exact device and
dimensions; mismatches allocate fresh. Training transitions back from SRV to UAV
before shading. Cells remain UAV. Ray record bytes are rewritten only after
retirement. Published outputs and target bindings remain immutable and retained
independently: output buffers are deliberately not recycled. Captures use fresh
scratch and are excluded from cache. Saves three committed allocations per
normal reused frame, not all allocation or tracing cost. No added GPU waits.
Pool active-owner budget is unchanged; idle cache has at most eight normal sets.

Four rays use one sample per guide and two cosine samples (alpha=.5, max p/q=2).
Ten rays retain 2+2+6, alpha=.4. Both use frozen invocation seed, same learned
R460 guide algorithm, fresh traversal and native shading. Divisors, invalid
clearing, hit-distance averaging and weight checks follow actual selected count.
Four-ray no-guide fallback uses four stratified cosine draws. Native producer
getter chooses the launch override before allocation/provider binding; original
one-pass/batch-zero admission remains required. Live four-ray execution and
image quality require user validation; a successful standalone test is not proof.

The two packages share a tested binary and differ in their launch ray-count
override and README. Saved settings remain untouched. The menu's saved sample
selection may differ from the launch override. Runtime producer logs report the
actual ray count plus scratch cache hits/misses. Compare FPS without F7 capture.

Validation: retirement-cycle test forbids reuse before completion and both seals;
GPU binding test checks scratch transfer does not recycle published targets.
Paired sampler tests cover both counts, unchanged range draws, mean integrals,
stale/blocked sources, and fitted versus wide source variance. Full production
compile and embedded-shader/package verification are required before delivery.
