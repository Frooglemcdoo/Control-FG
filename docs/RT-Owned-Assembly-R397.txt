R397 retains R396 record assembly and replaces the RT preparation query's grid
traversal. It uses temporary stack storage instead of native traversal allocations.

selection ordering remain intact. Nothing is cached across frames.
The replacement runs on the original preparation worker. Other query callers use
the native routine. Unsupported plane/depth shapes use the native query before
any owned selection is performed. Native AS builds remain; PTLAS is disabled.

4096 comparisons against the original selection machine code check output order,
plane masks, callback order, dirty flags, both grid layers and NaN/infinity cases.
The retained native callbacks are mocked in the isolated test; in-game validation
is needed. No FPS gain is promised. Logged query time includes retained callbacks
and is not total frame time or a native-versus-owned benchmark.
