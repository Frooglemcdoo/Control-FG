R471 changes source guide construction. Training hits map to canonical 0.5m
world-space source cells. Each guide sphere covers its entire source cell.
The second guide must represent a different cell, so opposite bright corners
of one cell cannot occupy both guide slots. Centers remain fixed when the
winning hit moves inside its cell. Different source cells can still change
rank between frames; this is not a temporal history filter.

Ray counts, mixture fractions, PDF correction and shaded radiance are retained.
Native replaced dispatches remain bypassed. No additional GPU pass, ray, or
brightness clamp. Guide construction retains R469's parallel stripe lists.
This is a visual-fix candidate, not a confirmed whole-game noise/FPS solution.
