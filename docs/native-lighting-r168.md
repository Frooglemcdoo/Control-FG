# R168: reuse identical centered spotlight traces

The user reports about 10 FPS recovered with R167 and SPEC Native. Both submitted R167 captures use specular request 0, GI 6, RR on, FG off and 2560x1440 launches. Native Blend recorded 68.55 presents/s versus Native 81.05; shadow-ray means were 1.686 and 0.253 ms. Other ray passes were 1.940 and 1.917 ms. Timing completed with zero errors/skips/faults. The full-frame difference is not wholly covered by these GPU stages.

Compiled R134 authored-clip shader SHA b025748befa88c52e683cf120e59a4748a1c9ce958559421d70f3c8c2fde52ec contains four spotlight TraceRay calls whose disk offsets are all zero. All segment definitions, including near-plane clipping, normalize identically. Trace parameters match; the payload is one distance float. The hit library has no global writes. The established centered filtering supplies softness downstream.

R168 removes only the three redundant payload resets and TraceRay calls. Existing payload loads reuse the first hit; visibility and blocker-distance aggregation, point tracing, closest/alpha/miss handlers, authored clipping, normals, selection, native PCF blend, soft filters, GI filtering and RR behavior are retained. No distance threshold, room cutoff or reduced launch resolution is introduced. This is three fewer spotlight traversal calls per selected spotlight pixel, not a claim of 75 percent total-frame savings. Driver optimization may already remove some redundant work; actual gain must be measured.

Build validation pins the original binary hash, rejects nonzero disk radii or differing segments/trace parameters, assembles the exact edited IR and requires DXIL validation before generating the embedded shader header. It preserves the original asset and outputs original/edited IR plus a validation manifest for review. Existing Windows shader, live-switching, capture and proxy/menu checks still apply. In-game visual/performance confirmation remains required.

SPEC now defaults to Native on startup, matching the user's accepted R167 setting. Higher quality choices remain independent of lighting mode. Native here means no specular sample override, not zero rays.

Install with Control closed. Leave RR on, FG off and SPEC Native. Send both ZIPs and report any visual difference. Each capture closes the overlay and waits five seconds after foreground gameplay resumes before recording twenty seconds.
