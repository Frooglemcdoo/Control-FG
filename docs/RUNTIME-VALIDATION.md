# Runtime validation baseline

The release core is based on v0.8.26, which passed fixed 2x–6x generation, native Dynamic MFG, live multiplier switching, and HDR lifecycle testing on the development system. Later development revisions through v0.8.35 focused on overlay, persistence, packaging, and hardware policy. v1.0.0 is the first public release built on that stabilized branch.

The machine-readable v0.8.26 result is included as `RUNTIME-BASELINE-v0.8.26.json`.
