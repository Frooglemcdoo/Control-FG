# Nexus / GitHub screenshot checklist

Use real in-game screenshots from the final v1.0.0 build. Recommended set:

1. **Hero image:** gameplay with the F10 overlay open in the top-right, showing the CONTROL FG wordmark and a working fixed mode.
2. **Dynamic MFG:** Dynamic selected with Auto target visible and a non-1x effective multiplier.
3. **6x MFG:** supported RTX 50-series system showing 6x selected/effective.
4. **HDR:** gameplay with HDR shown ON in the overlay.
5. **RTX 40-series policy:** optional screenshot from an RTX 40-series system showing Dynamic and 3x–6x greyed out.

Crop out unrelated desktop windows and personal information. Keep the game image visible enough that the overlay reads as part of Control rather than a standalone settings screenshot.
