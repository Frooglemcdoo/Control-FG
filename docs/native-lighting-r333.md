# R333 Owned GI performance build

Scene admission carries the validated BLAS slot into row processing. Shared geometry at different shader-table slots can reuse converted rows after an exact comparison of the native bytes within this submission. Material variants and conflicts still take the full validation path.

Geometry tracking grows the build journal geometrically and indexes retired snapshot buffers by device and exact size. Every snapshot still copies fresh geometry. Only fully retired buffers are eligible for reuse.
