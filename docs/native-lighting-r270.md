# R270 — independent spotlight GI lighting probes

## Evidence

R267 no-point GI did not help; no-spot GI cleared hair and most plant speckles. R268 PCF correction did not help. R269 combined PCF/VSM visibility bypass did not help either. User logs `Lighting-R204-20261101-091947-55764-0.log` show all eight R269 shaders prepared successfully and repeated unshadowed_spot binds (3120 at last logged count). Matching compact probe logs show raw_bypass complete=1, RR active during the test interval, and R268 PCF disabled. RR was disabled later in the session; that does not invalidate the earlier active interval. CPU pipeline observations are not GPU branch execution evidence.

These results deprioritize final shadow attenuation without disproving every possible visibility or geometry problem. Native shadow visibility is restored in all three new probes. None is a proposed shipping fix.

## Tests

Normal launch runs option 1. For other tests close the game and run `ControlTOH/Diagnostics/Start-GI-Lighting-Test.cmd`:

1. **White cookie**: bypass the multiplication by the spotlight projection texture at the secondary GI hit. Light color, falloff, shadows and material response remain native. This applies only to lights using that texture branch. Expect changes in the projected pattern and possibly brightness.
2. **Flat falloff**: replace the distance/radius attenuation after its zero clamp with constant 1/pi. Preserve native range fade, projection, shadows, light color, surface cosine and material response. This deliberately changes energy and may brighten distant bounce or dim close bounce. It tests sensitivity to distance attenuation; it is not an energy-preserving substitute and no improvement alone proves the formula is faulty.
3. **No Fresnel**: replace only the secondary diffuse Fresnel reduction with 1. Preserve N dot L, 1/pi, albedo, light parameters, projection, shadows and primary material response. This is not a hair-specific material bypass; the secondary surface may be another object.
4. **Native**: unmodified source GI lighting; accepted mod changes elsewhere remain.
5. **No spot**: the earlier source-removal reference. Spotlight GI removed; other contributions retained.

Keep lamp intact, RR and RT indirect ON, Native Blend, GI RAW BYPASS, identical GI sample count, FG OFF. Check F10 mode text. Compare the same plant/hair view both stationary and moving; report option numbers. Record brightness changes as well as speckles: darkening or washing out a noisy signal can hide it. Capture RR / Package RR remains available. Restart-scoped choices do not persist settings. Old source/shadow launchers are retained for explicit references, not required for the new tests.

## Implementation and validation

Each new shader is built independently from native bytes, with exact source SHA validation. One instruction is replaced and padded with NOPs: cookie RGB multiply, attenuation max, or final diffuse Fresnel complement. Context checks bind the target to the spotlight loop and projection atlas, and verify nearby arithmetic/data dependencies. Inverse patches reproduce the full native DXBC exactly. No temporal history, extra rays, clamp, filtering, or per-material/light identifiers are added. DirectStorage, reflections, primary RT spotlight visibility and R264 sample sequence are unchanged.

The existing Windows test validates all 56 source/visibility/lighting patches against generated bytecode, rejects changed native instructions, disassembles each shader, and creates WARP PSOs. This tests construction, not game-scene correctness or visual improvement.
