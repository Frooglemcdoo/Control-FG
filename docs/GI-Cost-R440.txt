R443 - Reuse invariant GI evaluator constants

Retains R434/R439 rays and R442 combined structured reads. Five constant
reads now execute once before the ray loop; four redundant reads share
existing identical CBV values. No lighting arithmetic, rays or RR inputs
are changed. Static address/CFG proofs and Windows GPU tests validate
this transformation. Performance on the RTX 5090 is not yet measured.

Close Control and extract beside Control_DX12.exe, replacing files.
Use RR ON, FG OFF, GI RAYS 10, GI GUIDE ON (FIXED), RELAX OFF, CONTACT AUTO.
Keep REF CLAMP at 60%. Check the lamp/Jesse view for the same clean image.

F10 -> GI COST CAPTURE now compares R442 and R443 automatically at TEN
rays throughout, in the same session. It no longer measures Native rays.
It checks the evaluator revision actually bound, not just the selection.
Seven phases: R442 / R443 / R443 / R442 / R443 / R443 no-query / R443.
Each phase has 5 seconds warmup and 12 seconds measurement.
An immediate beep confirms acceptance. Return to gameplay and remain
still for about two minutes. Two beeps and Explorer identify the report ZIP.
Send that ZIP. Ten rays and the R443 evaluator return after completion
or an aborted run. R442 is retained inside this build for the comparison.
